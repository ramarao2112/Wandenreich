# TC-001: AUTH-REQUIRED

## Overview
- **Rule ID:** `TC-001`
- **Rule Name:** `AUTH-REQUIRED`
- **Severity:** `Error`
- **Target:** Endpoint declarations

## Trigger
An endpoint lacks an explicit authentication declaration (`auth: required` or `auth: public`).

## Rationale
Endpoints without declared authentication expose operations to arbitrary unauthenticated callers by default. TrustSpec requires every endpoint to explicitly declare its authentication boundary to prevent accidental exposure of sensitive operations or data.

## Fix Options
1. **Require Authentication (Suggested Restrictive Default):**
   Add `auth: required` to the endpoint block. Callers must provide a valid JWT bearer token.
   ```trust
   endpoint GET /trips/{id}:
     resource: Trip
     auth: required
     returns: Trip
   ```
2. **Declare Public Access (Explicit Business Decision):**
   If the endpoint is intentionally accessible to anonymous users, explicitly declare `auth: public`.
   ```trust
   endpoint GET /trips:
     resource: Trip
     auth: public
     returns: Trip
   ```

*Note: The suggested automated diff provides `auth: required` as a safe default. Making an endpoint public must always be an intentional, explicit developer action.*
