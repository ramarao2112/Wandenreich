# TC-005: SECRET-SCOPE

## Overview
- **Rule ID:** `TC-005`
- **Rule Name:** `SECRET-SCOPE`
- **Severity:** `Error`
- **Target:** Top-level `secrets:` declaration block

## Trigger
The TrustSpec specification is missing one or both of the mandatory runtime environment secret references:
- `DB_URL: env`
- `JWT_SECRET: env`

## Rationale
Generated backend services require database connectivity and a secret key for signing and verifying JSON Web Tokens (JWT). Omitting these declarations prevents secure configuration via environment variables and would lead to either hardcoded fallback secrets or runtime startup failure.

## Fix Options
- **Declare Required Environment Secrets (Automated Fix):**
  Ensure both `DB_URL` and `JWT_SECRET` are declared in the top-level `secrets:` block:
  ```trust
  secrets:
    DB_URL: env
    JWT_SECRET: env
  ```
  *(Only the secret variable names are declared; secrets are read from runtime environment variables, never hardcoded in the specification.)*
